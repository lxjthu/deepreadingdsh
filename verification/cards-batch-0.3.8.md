# 高亮批量制卡与卡片编辑 0.3.8

日期：2026-11-19。本次读取实际安装插件为 0.3.7，继续保留所有既有改动；未控制桌面界面、未修改原论文、未重新 OCR、未调用真实模型。

## 本次改动

- 高亮文本条目支持多选、全选和取消全选，单批最多 200 条，每条高亮独立排队。相同选段复用已有任务，逐条显示失败并保留失败项勾选。
- 新高亮记录真实 PDF 哈希和词/字符位置；旧高亮必须同时匹配原句与区域。备注编辑不删除来源字段。
- “预览卡片”打开专用预览编辑窗口，提供正文编辑与 Markdown 预览、原引文、前后文、来源题录和导出。可另开独立窗口；未保存关闭有提醒，旧窗口不能覆盖另一窗口的新修改。
- 卡片保存生成时的题录快照，含题名、作者、年份、期刊、卷、期、文献页码、DOI 和语言；旧卡片显示当前题录补充标记。Markdown YAML 同步包含题录与来源类型。

## 用户测试步骤

1. 升级至 0.3.8 后重新打开一篇 PDF，使用“高亮”标出两段文字。
2. 在“高亮选段”区勾选两条，或点“全选高亮”，点击“生成所选卡片”。检查每段对应一个任务，已存在选段显示复用；失败项应有具体原因。
3. 完成后点击“预览卡片”，检查预览编辑窗口的标题、摘要、标签、正文、题录属性、原文和上下文。
4. 修改内容并保存，关闭再打开；导出 Markdown，检查来源题录 YAML 和原文位置。旧卡片的题录应注明来自当前文献库。
5. 点击“在独立窗口打开”。若浏览器未弹出，点击直接链接；在两个窗口修改同一卡片，后保存的旧窗口应提示冲突。
6. 刷新/重启后确认标记、卡片与来源仍保留。无法定位的旧高亮需重新核对并高亮，不应自动猜测。

界面操作、真实论文的选区体验及真实模型输出仍由用户验收。
